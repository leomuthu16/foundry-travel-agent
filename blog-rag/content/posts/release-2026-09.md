DataHub 2026.9 adds event-based pipeline triggers and a new monitoring hub.

## Pipelines
Pipelines can now start when an event happens, for example when a new file arrives in a storage folder. The maximum number of concurrent pipeline runs per workspace is raised from 20 to 50.

## Notebooks
GPU-backed notebook sessions are available in preview for machine learning workloads.

## Monitoring
The new monitoring hub shows the run history of all pipelines and notebooks in a workspace for the last 90 days.
