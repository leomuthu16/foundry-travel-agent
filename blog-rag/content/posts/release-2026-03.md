DataHub 2026.3 focuses on reliability and data security.

## Pipelines
Failed pipeline activities can now be retried automatically. You can set up to 3 retries per activity and a delay between attempts. Pipeline parameters can now have default values, which makes pipelines easier to reuse.

## Security
Row-level security for datasets is available in preview. Dataset owners can define security roles that limit which rows each user can see.

## Connectors
The Snowflake connector is now generally available.
